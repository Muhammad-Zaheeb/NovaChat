# NovaChat 💬

A production-ready real-time messaging platform built with React, FastAPI, PostgreSQL, SQLAlchemy, JWT Authentication, and WebSockets.

---

## 🚀 Tech Stack

### Frontend

- React
- TypeScript
- Vite
- Zustand
- React Router
- Axios

### Backend

- FastAPI
- PostgreSQL
- SQLAlchemy 2.0
- Alembic
- JWT
- WebSockets

---

## Features

- User Authentication
- Real-time Messaging
- Group Chats
- Typing Indicators
- Read Receipts
- Online Presence
- File Sharing
- Voice Messages
